# Microsoft Documentation

## Core Principles
- Prefer Microsoft Learn and official product documentation for Microsoft technologies.
- Check current documentation for version-sensitive features and commands.
- Distinguish conceptual guidance from API reference.
- Verify preview status and prerequisites before recommending preview features.
- Do not treat old blog posts as authoritative when current product documentation differs.
